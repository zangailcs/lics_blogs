# 1、穷鬼的搭梯子方案

*Q：为什么不直接租机场服务？*

*A：机场服务按月购买单价并不低，半年起充又容易遇到机场卷款跑路，得不偿失；另外，机场服务器可能会遇到限速、限流量等问题。*

​        搭梯子的主要成本是需要购买一台带有公网能力的海外VPS（Virtual Private Server，虚拟主机/云服务器），而Hostwinds、搬瓦工、Vultr等主流的VPS厂商，最便宜的VPS也需要5美元/月，对日常使用而言成本较高。

​        Vultr对于新注册的账号有首充多少送多少的活动，赠送额度的有效期为一年，每年使用QQ邮箱注册新Vultr账号，首充30美元到账60美元，刚好可以使用一年5美元/月的VPS，**折合成本2.5美元/月**。

- 活动链接：https://www.vultr.com/coupons/

  - 选择 VULTRMATCH 优惠

  ![Vultr充多少送多少优惠活动](https://picgo-img-lcs.oss-cn-shanghai.aliyuncs.com/image-20251208182210418.png)

  - 首年内，以在Vultr消费5美元为例，**会从充值额度和赠送额度里分别扣2.5美元**，一年总计需要12*5=60美元，充30美元赠送的30美元一年刚好用完

- 每月流量上限：1T（根本用不完）

- 支持按量付费，VPS可以随时销毁，不满一个月按小时折算实际价格

## 1.3 搭建V2Ray服务

注：参考教程：https://github.com/233boy/v2ray

（1）在Vultr控制台查看VPS的IPv4地址、帐号密码：

<img src="https://picgo-img-lcs.oss-cn-shanghai.aliyuncs.com/image-20251208190532712.png" alt="Vultr查看VPS信息" style="width: 50%; height: auto;">

（2）打开命令行，ssh登录VPS：

```shell
ssh root@{VPS ip地址}
```

随后输入密码。

（3）关闭防火墙：否则端口不通，梯子连接不上。

```shell
systemctl stop firewalld; systemctl disable firewalld; ufw disable
```

（4）执行一键安装脚本：

```shell
bash <(wget -qO- -o- https://github.com/233boy/v2ray/raw/master/install.sh)
```

回显会输出一大串“vmess://”开头的链接地址，复制后，打开V2Ray软件选择从剪切板导入，并设为活动服务器即可。

（5）可以尽情地开始学习了：
